## How to Add Sample Properties

Once you have created a user account via the authentication system:

### Option 1: Via UI (Recommended)
1. Log in to your account
2. Navigate to the Experiences page
3. Click "List Your Property" button
4. Fill out the 4-step form with the details from any property above
5. Submit for approval
6. As an admin, you can manually approve the property in the database

### Option 2: Via SQL (After User Creation)
